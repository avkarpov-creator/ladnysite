VPS Infrastructure as Code

Разработан · локально протестирован

Задача — создать воспроизводимую VPS-инфраструктуру с автоматизированной настройкой операционной системы и прикладных сервисов.

Terraform · Yandex Cloud · Ansible · Docker Compose · Nginx · Bash · GitHub Actions · Gitleaks

Реализовано

  • Terraform-конфигурация для Yandex Cloud описывает виртуальную машину, сеть, подсеть, статический IPv4 и группы безопасности.
  • Ansible настраивает Linux, SSH, пользователей и firewall, устанавливает Docker и Nginx. Docker Compose развёртывает тестовое приложение.
  • deploy.sh передаёт параметры Terraform в Ansible. Процедуры развёртывания и отката задокументированы.
  • GitHub Actions проверяет конфигурации, Gitleaks ищет секреты.

Результаты проверки

  • Пройдены terraform validate и синтаксические проверки Ansible.
  • Проверен локальный запуск Docker Compose и Nginx.
  • Проверена обработка ошибок скриптом развёртывания.

Облачное развёртывание ожидает проверки.

Kubernetes Observability

Работающий лабораторный проект

Задача — настроить мониторинг двух действующих сайтов с сохранением их рабочей инфраструктуры. Источники метрик — действующие веб-сервисы, а сбор и обработка выполняются в лабораторном кластере kind на WSL2.

Kubernetes · kind · WSL2 · SSH · FastAPI · Prometheus · Grafana · Alertmanager

Реализовано

  • Каждые 30 секунд по SSH собираются данные журналов сайтов для расчёта агрегированных HTTP-метрик.
  • FastAPI предоставляет метрики для Prometheus. В Grafana видны HTTP-запросы, ошибки 5xx и популярные страницы.

Результаты проверки

  • Проверено срабатывание алертов при остановке приложения.
  • Проверено восстановление после повторного запуска приложения.

Disaster Recovery — Yandex Cloud

Выполненный практический кейс

Задача — восстановить доступность веб-инфраструктуры после инцидента у хостинг-провайдера.

Архитектура. DNS направляет трафик на резервную виртуальную машину в Yandex Cloud, а Nginx принимает HTTPS-запросы.

Yandex Cloud · Linux · Nginx · DNS · HTTPS/TLS · Terraform

Реализовано

Вручную создана резервная ВМ, настроены Linux, Nginx, DNS и HTTPS/TLS. Для последующей автоматизации подготовлена конфигурация Terraform.

Результат

Доступность веб-инфраструктуры восстановлена на резервной ВМ.

Critical Infrastructure — ВГТРК

Инженерный опыт · 2011–2023

Задача — поддерживать доступность инфраструктуры четырёх телевизионных студий, диагностировать сбои и обеспечивать техническое сопровождение прямых эфиров федерального уровня.

Архитектура. Около 70 рабочих станций Windows, macOS и Linux, рендер-ферма из шести узлов, сетевые хранилища Synology и RAID-массивы, службы каталогов Active Directory и Open Directory.

Windows · macOS · Linux · Synology · RAID · Active Directory · Open Directory · Cisco · WebRTC

Инженерная работа

  • Эксплуатация рабочих станций, рендер-фермы и сетевых хранилищ.

  • Настройка рабочих станций для приёма WebRTC-видеопотоков.

Результат
